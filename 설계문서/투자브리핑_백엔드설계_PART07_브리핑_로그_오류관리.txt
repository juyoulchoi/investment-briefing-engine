투자 브리핑 Spring Boot 백엔드 설계
PART 07. 브리핑·브리핑항목·API로그·스케줄러로그·오류로그 상세설계
대상 테이블:
TB_BRF, TB_BRF_ITEM, TB_API_LOG, TB_SCH_LOG, TB_ERR_LOG
============================================================

문서 목적
------------------------------------------------------------
이 문서는 투자 브리핑 시스템의 브리핑 저장, 항목별 구성,
OpenAI 설명 생성, 외부 API 호출이력, 스케줄러 실행이력,
시스템 오류로그를 상세 설계한다.

대상 테이블
1. TB_BRF      : 투자 브리핑 헤더 및 본문
2. TB_BRF_ITEM : 투자 브리핑 항목
3. TB_API_LOG  : 외부 API 호출이력
4. TB_SCH_LOG  : 스케줄러 실행이력
5. TB_ERR_LOG  : 시스템 오류로그

이번 문서에서 연결하는 주요 기능
- 일일·주간·월간 투자 브리핑
- 평일 오전 자동 브리핑 생성
- 한국시장 전일 마감요약
- 시장국면
- 시장심리
- 정기매수 신호
- 추가매수 신호
- 재매수 신호
- 계좌별 현금상태
- 종목별 신호등
- 리밸런싱 결과
- OpenAI 설명 생성
- 브리핑 생성·검토·발행 상태
- 외부 API 호출 성공·실패
- 스케줄러 실행 성공·실패
- 예외 및 오류 추적

※ 계산 결과는 Java 계산엔진이 생성한다.
※ OpenAI는 계산결과를 바꾸지 않고 자연어 설명만 생성한다.
※ 브리핑 원천값과 생성문을 분리하여 저장한다.
※ 동일 기준일 브리핑 재생성 시 계산순번과 최신 여부를 관리한다.


============================================================
1. 브리핑 생성 기본 원칙
============================================================

1.1 브리핑 유형
------------------------------------------------------------

DAILY
- 일일 투자 브리핑
- 전일 또는 최근 거래일 시장 마감 포함
- 계좌별 투자판단 포함

WEEKLY
- 주간 투자 브리핑
- 주간 수익률, 수급, 리밸런싱 결과 포함

MONTHLY
- 월간 투자 브리핑
- 월간 성과, 목표비중, 현금비중, 전략 변경 포함

AD_HOC
- 수시 브리핑
- 급락, 급등, 중요 실적, 정책변화 등 특별상황

# 주석
# 브리핑 유형은 BRF_TP 컬럼으로 구분한다.
# 같은 기준일에도 계좌별 또는 전체 브리핑을 별도로 생성할 수 있다.


1.2 브리핑 대상 범위
------------------------------------------------------------

GLOBAL
- 전체 계좌 및 전체 시장

ACCOUNT
- 특정 계좌

MARKET
- 특정 시장

STOCK
- 특정 종목

저장 컬럼
- SCOPE_TP
- ACCT_ID
- MKT_SNAP_CD
- STK_ID

# 주석
# 범위에 따라 관련 ID는 NULL을 허용한다.
# 예: 전체 일일 브리핑은 SCOPE_TP = GLOBAL, ACCT_ID = NULL


1.3 브리핑 생성 상태
------------------------------------------------------------

READY
- 원천 계산결과 준비 완료

GENERATING
- OpenAI 설명 생성 중

GENERATED
- 설명 생성 완료

REVIEWED
- 검토 완료

PUBLISHED
- 발행 완료

FAILED
- 생성 실패

CANCELLED
- 취소

# 주석
# 생성 실패 시 기존 정상 브리핑을 덮어쓰지 않는다.
# 재생성 시 새로운 CALC_SEQ를 사용한다.


1.4 브리핑 14개 고정 항목
------------------------------------------------------------

권장 항목 코드

01. KR_MARKET_CLOSE

- 외국인 선물

CREATE TABLE TB_BRF (
    BRF_ID               BIGINT GENERATED BY DEFAULT AS IDENTITY,
    BASE_DT              DATE                    NOT NULL,
    CALC_SEQ             INTEGER                 NOT NULL DEFAULT 1,
    BRF_TP               VARCHAR(20)             NOT NULL,
    SCOPE_TP             VARCHAR(20)             NOT NULL,
    ACCT_ID              BIGINT,
    STK_ID               BIGINT,
    MKT_SNAP_CD          VARCHAR(30),
    INV_DEC_ID           BIGINT,
    REBAL_ID             BIGINT,
    BRF_STS              VARCHAR(20)             NOT NULL DEFAULT 'READY',
    TITLE                VARCHAR(300)            NOT NULL,
    SUMMARY_TXT          TEXT,
    BODY_TXT             TEXT,
    RAW_DATA_JSON        JSONB,
    AI_MODEL_NM          VARCHAR(100),
    AI_PROMPT_VER        VARCHAR(50),
    AI_REQ_ID            VARCHAR(100),
    AI_INPUT_TOKEN_CNT   INTEGER,
    AI_OUTPUT_TOKEN_CNT  INTEGER,
    AI_COST_AMT          NUMERIC(20,8),
    AI_GEN_DTTM          TIMESTAMP WITH TIME ZONE,
    DATA_STS             VARCHAR(20)             NOT NULL,
    CONF_RT              NUMERIC(10,4)           NOT NULL,
    LATEST_YN            CHAR(1)                 NOT NULL DEFAULT 'Y',
    PUBL_YN              CHAR(1)                 NOT NULL DEFAULT 'N',
    PUBL_DTTM            TIMESTAMP WITH TIME ZONE,
    PUBL_CHNL            VARCHAR(30),
    FAIL_RSN             VARCHAR(2000),
    CRT_DTTM             TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CRT_USR_ID           VARCHAR(50),
    UPD_DTTM             TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UPD_USR_ID           VARCHAR(50),

    CONSTRAINT PK_TB_BRF PRIMARY KEY (BRF_ID),
    CONSTRAINT UK_TB_BRF_01 UNIQUE (
        BASE_DT,
        CALC_SEQ,
        BRF_TP,
        SCOPE_TP,
        ACCT_ID,
        STK_ID,
        MKT_SNAP_CD
    ),
    CONSTRAINT FK_TB_BRF_01 FOREIGN KEY (ACCT_ID)
        REFERENCES TB_ACCT (ACCT_ID),
    CONSTRAINT FK_TB_BRF_02 FOREIGN KEY (STK_ID)
        REFERENCES TB_STK (STK_ID),
    CONSTRAINT FK_TB_BRF_03 FOREIGN KEY (INV_DEC_ID)
        REFERENCES TB_INV_DEC (INV_DEC_ID),
    CONSTRAINT FK_TB_BRF_04 FOREIGN KEY (REBAL_ID)
        REFERENCES TB_REBAL (REBAL_ID),
    CONSTRAINT CK_TB_BRF_01 CHECK (CALC_SEQ > 0),
    CONSTRAINT CK_TB_BRF_02 CHECK (
        BRF_TP IN ('DAILY', 'WEEKLY', 'MONTHLY', 'AD_HOC')
    ),
    CONSTRAINT CK_TB_BRF_03 CHECK (
        SCOPE_TP IN ('GLOBAL', 'ACCOUNT', 'MARKET', 'STOCK')
    ),
    CONSTRAINT CK_TB_BRF_04 CHECK (
        BRF_STS IN (
            'READY',
            'GENERATING',
            'GENERATED',
            'REVIEWED',
            'PUBLISHED',
            'FAILED',
            'CANCELLED'
        )
    ),
    CONSTRAINT CK_TB_BRF_05 CHECK (
        DATA_STS IN ('FRESH', 'STALE', 'MISSING', 'PARTIAL', 'ERROR')
    ),
    CONSTRAINT CK_TB_BRF_06 CHECK (
        CONF_RT BETWEEN 0 AND 100
    ),
    CONSTRAINT CK_TB_BRF_07 CHECK (LATEST_YN IN ('Y', 'N')),
    CONSTRAINT CK_TB_BRF_08 CHECK (PUBL_YN IN ('Y', 'N')),
    CONSTRAINT CK_TB_BRF_09 CHECK (
        AI_INPUT_TOKEN_CNT IS NULL OR AI_INPUT_TOKEN_CNT >= 0
    ),
    CONSTRAINT CK_TB_BRF_10 CHECK (
        AI_OUTPUT_TOKEN_CNT IS NULL OR AI_OUTPUT_TOKEN_CNT >= 0
    ),
    CONSTRAINT CK_TB_BRF_11 CHECK (
        AI_COST_AMT IS NULL OR AI_COST_AMT >= 0
    )
);

CREATE INDEX IDX_TB_BRF_01
    ON TB_BRF (BASE_DT DESC);

CREATE INDEX IDX_TB_BRF_02
    ON TB_BRF (BRF_TP, BASE_DT DESC);

CREATE INDEX IDX_TB_BRF_03
    ON TB_BRF (ACCT_ID, BASE_DT DESC);

CREATE INDEX IDX_TB_BRF_04
    ON TB_BRF (BRF_STS, BASE_DT DESC);

CREATE INDEX IDX_TB_BRF_05
    ON TB_BRF (LATEST_YN, PUBL_YN, BASE_DT DESC);

CREATE INDEX IDX_TB_BRF_06
    ON TB_BRF USING GIN (RAW_DATA_JSON);

11.1 TbBrf
------------------------------------------------------------

@Entity
@Table(
    name = "TB_BRF",
    uniqueConstraints = {
        @UniqueConstraint(
            name = "UK_TB_BRF_01",
            columnNames = {
                "BASE_DT",
                "CALC_SEQ",
                "BRF_TP",
                "SCOPE_TP",
                "ACCT_ID",
                "STK_ID",
                "MKT_SNAP_CD"
            }
        )
    }
)
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class TbBrf {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "BRF_ID")
    private Long briefingId;

    @Column(name = "BASE_DT", nullable = false)
    private LocalDate baseDate;

    @Enumerated(EnumType.STRING)
    @Column(name = "BRF_TP", nullable = false, length = 20)
    private BriefingType briefingType;

    @Enumerated(EnumType.STRING)
    @Column(name = "SCOPE_TP", nullable = false, length = 20)
    private BriefingScopeType scopeType;

    @Enumerated(EnumType.STRING)
    @Column(name = "BRF_STS", nullable = false, length = 20)
    private BriefingStatus briefingStatus;

    @Column(name = "TITLE", nullable = false, length = 300)
    private String title;

    @Column(name = "SUMMARY_TXT", columnDefinition = "TEXT")
    private String summaryText;

    @Column(name = "BODY_TXT", columnDefinition = "TEXT")
    private String bodyText;

    @JdbcTypeCode(SqlTypes.JSON)
    @Column(name = "RAW_DATA_JSON", columnDefinition = "jsonb")
    private String rawDataJson;

    @Column(name = "CONF_RT", nullable = false, precision = 10, scale = 4)
    private BigDecimal confidenceRate;
}


11.2 TbBrfItem
------------------------------------------------------------

@Entity
@Table(
    name = "TB_BRF_ITEM",
    uniqueConstraints = {
        @UniqueConstraint(
            name = "UK_TB_BRF_ITEM_01",
            columnNames = {"BRF_ID", "ITEM_CD"}
        )
    }
)
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class TbBrfItem {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "BRF_ITEM_ID")
    private Long briefingItemId;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "BRF_ID", nullable = false)
    private TbBrf briefing;

    @Column(name = "ITEM_CD", nullable = false, length = 50)
    private String itemCode;

    @Column(name = "ITEM_NM", nullable = false, length = 150)
    private String itemName;

    @Column(name = "DISP_SEQ", nullable = false)
    private Integer displaySequence;

    @Column(name = "CALC_SUMMARY", columnDefinition = "TEXT")
    private String calculationSummary;

    @Column(name = "AI_TEXT", columnDefinition = "TEXT")
    private String aiText;

    @Column(name = "FINAL_TEXT", columnDefinition = "TEXT")
    private String finalText;
}

18. 오류 처리 정책
============================================================

외부 API 실패
- 재시도
- 마지막 정상값 사용 여부 판단

- 해당 TB_BRF_ITEM.ITEM_STS = FAILED
- 전체 브리핑은 PARTIAL 데이터 상태로 생성 가능
- 실패항목은 계산요약만 노출 가능

# 주석
# OpenAI 실패가 투자판단 실패로 이어지면 안 된다.
# 계산결과는 항상 별도로 조회 가능해야 한다.
