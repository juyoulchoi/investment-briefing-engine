투자 브리핑 Spring Boot 백엔드 설계
PART 06. 주간·월간 리밸런싱 상세설계
대상 테이블: TB_REBAL, TB_REBAL_ITEM
============================================================

문서 목적
------------------------------------------------------------
이 문서는 계좌별 주간·월간·수시 리밸런싱 계획과 종목별 조정항목을 설계한다.

대상 테이블
1. TB_REBAL      : 리밸런싱 계획 헤더
2. TB_REBAL_ITEM : 종목별 리밸런싱 항목

연결 계산
- 계좌 총자산
- 현재·목표 현금비중
- 종목 현재·목표비중
- 비중 부족·초과금액
- 추천 매수·매도금액
- 정기매수 증액·감액·중단·재개
- 실행 우선순위
- 승인·부분실행·완료상태

기본 원칙
------------------------------------------------------------
- 국내계좌, 해외계좌, ISA계좌, 연금계좌를 각각 별도로 계산한다.
- 주간 리밸런싱은 정기매수 조정과 신규 현금배분 중심으로 운영한다.
- 월간 리밸런싱은 필요 시 실제 매도까지 검토한다.
- 장기투자 계좌는 매도보다 신규입금과 정기매수 조정으로 비중을 복구한다.
- 펀더멘털 훼손 종목은 예외적으로 우선 매도 검토가 가능하다.
- OpenAI는 계산하지 않고 저장된 결과를 설명한다.

============================================================
1. 리밸런싱 계산식
============================================================

계좌 총자산
TOT_AST_AMT = CASH_AMT + RSV_CASH_AMT + SUM(EVL_AMT)

종목 목표금액
TGT_AMT = TOT_AST_AMT × TGT_WGT / 100

종목 현재금액
CUR_AMT = EVL_AMT

비중 차이금액
WGT_GAP_AMT = TGT_AMT - CUR_AMT

매수 필요금액
BUY_NEED_AMT = MAX(WGT_GAP_AMT, 0)

매도 필요금액
SELL_NEED_AMT = MAX(-WGT_GAP_AMT, 0)

현재 전체 현금
CUR_CASH_AMT = CASH_AMT + RSV_CASH_AMT

목표 현금금액
TGT_CASH_AMT = TOT_AST_AMT × TGT_CASH_WGT / 100

현금 차이금액
CASH_GAP_AMT = CUR_CASH_AMT - TGT_CASH_AMT

추천 매수금액
RCMD_BUY_AMT = MIN(
  BUY_NEED_AMT,
  계좌 매수예산 잔액,
  종목별 최대 매수금액,
  목표비중 부족금액
)

추천 매도금액
RCMD_SELL_AMT = MIN(
  SELL_NEED_AMT,
  보유 평가금액,
  계좌별 매도목표금액 잔액
)

정기매수 변경액
REG_BUY_CHG_AMT = NEW_REG_BUY_AMT - CUR_REG_BUY_AMT

해석
- 양수: 정기매수 증액
- 음수: 정기매수 감액
- 0: 유지

3. TB_REBAL_ITEM 종목별 리밸런싱 항목
============================================================

------------------------------------------------------------

비중차이, 추천 매수·매도금액, 정기매수 조정, 실행결과를 저장한다.

============================================================

리밸런싱 상태
DRAFT → CALCULATED → REVIEWED → APPROVED
→ PARTIALLY_EXECUTED 또는 COMPLETED
취소 시 CANCELLED

항목 상태
READY → APPROVED → EXECUTED
부분 실행 시 PARTIALLY_EXECUTED
미실행 결정 시 SKIPPED
취소 시 CANCELLED

@Entity
@Table(name = "TB_REBAL")
@Getter @Setter @NoArgsConstructor @AllArgsConstructor @Builder
public class TbRebal {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "REBAL_ID")
    private Long rebalanceId;

    @Column(name = "BASE_DT", nullable = false)
    private LocalDate baseDate;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "ACCT_ID", nullable = false)
    private TbAcct account;

    @Enumerated(EnumType.STRING)
    @Column(name = "REBAL_TP", nullable = false, length = 20)
    private RebalanceType rebalanceType;

    @Enumerated(EnumType.STRING)
    @Column(name = "REBAL_STS", nullable = false, length = 30)
    private RebalanceStatus rebalanceStatus;

    @Column(name = "TOT_AST_AMT", nullable = false, precision = 20, scale = 4)
    private BigDecimal totalAssetAmount;
}

@Entity
@Table(name = "TB_REBAL_ITEM")
@Getter @Setter @NoArgsConstructor @AllArgsConstructor @Builder
public class TbRebalItem {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "REBAL_ITEM_ID")

11. 검증 규칙
============================================================

TB_REBAL
- 추천 매수총액은 매수예산 이하
- 추천 매도총액은 계좌 보유평가금액 이하
- 최신 리밸런싱은 기준일·계좌·유형별 1건
- 총자산과 모든 금액은 0 이상

TB_REBAL_ITEM
- 추천 매수금액과 추천 매도금액이 동시에 양수이면 안 됨
- BUY이면 RCMD_SELL_AMT = 0
- SELL이면 RCMD_BUY_AMT = 0
- 실행수량은 보유수량을 초과할 수 없음
- 거래제한 Y이면 실행 불가
- 펀더멘털 훼손 Y이면 매수 불가
- MIN_WGT <= TGT_WGT <= MAX_WGT
- 실행금액이 추천금액을 초과하면 사유 필수
