Investment Briefing Engine - Local API 목록
=============================================

작성 기준
---------
- 기준 브랜치: main
- 기준 소스: backend/src/main/java 하위 @RestController
- Docker Compose Local Backend URL: http://localhost:8081
- Swagger UI: http://localhost:8081/swagger-ui.html
- Swagger UI 직접 경로: http://localhost:8081/swagger-ui/index.html
- OpenAPI JSON: http://localhost:8081/v3/api-docs
- OpenAPI YAML: http://localhost:8081/v3/api-docs.yaml
- 전체 API 수: 85개

주의
----
- 아래 목록은 애플리케이션이 직접 선언한 Local REST API다.
- Path Variable은 {이름}, Query Parameter는 Swagger UI에서 확인하고 입력한다.
- POST, PUT, PATCH, DELETE는 DB 변경이나 외부 데이터 수집을 실행할 수 있으므로 Swagger의 Try it out 사용 시 주의한다.
- KRX, Yahoo, FRED 수집 API는 로컬 API이지만 실행 시 외부 공급자 API를 호출한다.

Swagger 사용 방법
-----------------
1. 로컬 Backend를 실행한다.
2. 브라우저에서 http://localhost:8081/swagger-ui.html 을 연다.
3. Controller별로 자동 분류된 API를 펼친다.
4. 실행할 API에서 Try it out을 누른다.
5. Path Variable, Query Parameter 또는 Request Body를 입력한다.
6. Execute를 누르고 Request URL, 응답 상태 및 응답 Body를 확인한다.

기계 판독용 OpenAPI 명세
------------------------
- JSON: GET http://localhost:8081/v3/api-docs
- YAML: GET http://localhost:8081/v3/api-docs.yaml

API 추가 시 관리 원칙
---------------------
- @RestController 및 Mapping 선언을 추가하면 Springdoc이 Swagger에 자동 반영한다.
- 복잡한 API는 @Tag, @Operation, @Parameter, @Schema 설명을 추가한다.
- API 경로나 method를 변경하면 이 문서도 함께 갱신한다.
- Swagger JSON을 최종 기준으로 삼고 이 파일은 사람이 빠르게 확인하는 인덱스로 사용한다.
